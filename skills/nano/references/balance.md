# xno-skills balance

```
Usage: xno-skills balance [options]

Show balances and pending amounts

Options:
  --wallet <name>  OWS wallet name (repeat for a batch) (default: [])
  --count <n>      Max receivable blocks to return if pending > 0 (default: 10)
  -j, --json       Output in JSON format
  -h, --help       display help for command
```
